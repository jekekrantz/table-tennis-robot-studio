# Robust calibration refit — fixed geometry, one global linear speed law

## Model

The only wheel-input → launch-speed relation is

\[
v(r)=a+br.
\]

There are no speed knots and no piecewise interpolation. Fitting solves `a` and `b` jointly from all currently included observations.

The robot launch coordinate is generated by the fixed chain:

```text
base back -> yaw pivot      0.242 m
yaw pivot -> pitch pivot    0.075 m
pitch pivot -> wheels       0.075 m
yaw pivot height            0.240 m
```

These dimensions are constants, not fit parameters.

## Measurement likelihood and robustness

For a ground landing observation, the relative standard deviation is

\[
\sigma_i = 0.015\,\mathrm{m}\;\frac{|d_i|}{\sin(\alpha_i)},
\]

where `d_i` is predicted distance and `alpha_i` is predicted incidence angle with the ground. A small numerical floor is used for `sin(alpha)` to prevent singular weights at extremely shallow incidence.

After fitting the global line, distance residuals are divided by their individual `sigma_i`. The solver computes the median and MAD of those standardized residuals, rejects values beyond 3.5 robust standard deviations, and refits until the active set stabilizes.

Measurement offset is applied before fitting as:

```text
corrected distance = entered distance + offset
```

The screenshot distances in this refit were already manually corrected, so the refit uses offset = 0.


Diagnostics:

- 26 readable distance observations
- 24 retained
- 2 iterative-MAD rejections
- retained landing RMSE: 4.43697 cm
- all-point landing RMSE: 5.90976 cm
- mean retained signed error (`predicted - measured`): +0.652 cm
- retained elevation trend: about -1.109 cm per 10°
- retained raw-input trend: about +0.328 cm per 100 raw

Rejected observations:

- raw 2000, elevation 5°
- raw 2000, elevation 15°

Because both rejected values occur at the lowest raw setting, they should be treated as diagnostic flags rather than assumed measurement mistakes. More low-raw measurements would distinguish a measurement issue from real low-speed nonlinearity; the application model remains deliberately affine unless there is strong evidence to change that design decision.
