# Nova side-profile candidates

Five original SVG interpretations of the Pongbot Nova S Pro, drawn from public product-photo reference without embedding or tracing a product image:

1. `nova-side-1-silhouette.svg` — simple filled silhouette.
2. `nova-side-2-technical.svg` — labeled technical outline.
3. `nova-side-3-product.svg` — layered product-style drawing; this visual language is used in the placement UI.
4. `nova-side-4-compact.svg` — reduced small-screen icon.
5. `nova-side-5-high-contrast.svg` — maximum-contrast accessible outline.

All share the recognizable rectangular base, translucent rear hopper, arched rotating launcher body, orange yaw ring, and oversized dual-wheel launcher housing.
