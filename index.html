    STOP first to leave Nova quiet but quickly reusable, then disconnect BLE after longer inactivity.

    STOP after no shots
    i
    STOP ends robot activity while keeping Bluetooth connected. If Nova becomes Uninitialized, the next drill initializes it automatically; this is normally much faster than reconnecting Bluetooth. A separate physical head-parking move remains disabled until verified non-firing on the robot.

    Disconnect BLE when unused
    i
    BLE disconnect performs the orderly STOP stage first, then closes the Bluetooth connection. Starting again requires the browser device chooser and Nova authentication, so this timeout is longer than STOP.

    Robot calibration

    Calibrate the launch-speed model, physical geometry and table dimensions.

    How to collect the data
    1. Use no spin: top and bottom wheel inputs are kept equal.
    2. Measure first-bounce distance in cm. Table mode can reference the net; ground mode always references the back of the robot base.
    3. When calibrating on the table, you can optionally measure clearance from the bottom of the ball to the top of the net.
    4. Press Save value & next. Blank fields are allowed and simply advance the plan.

    Compute calibration

    Not computed

    The measured pivot geometry is fixed. The fit optimizes exactly two speed parameters: intercept and slope. Distance uncertainty scales with predicted distance / sin(incidence), followed by iterative MAD rejection.

    Robot / model settings

    Physical head orientation and advanced launch-model controls. Robot position is calibrated from the Run screen.

    Fixed measured geometry: base back → yaw pivot 24.2 cm; yaw → pitch pivot 7.5 cm; pitch pivot → wheels 7.5 cm; yaw pivot 24.0 cm above the support surface. Pitch and yaw/aim move the physical release point.
