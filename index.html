    Trajectory model

    Drag and Magnus model from Conti et al. (2026), arXiv:2606.28805 for the first free-flight segment. Spin is held constant during this short flight, matching the published model.

    Advanced trajectory settings

    Normally leave these at the published-model/ITTF defaults. Change them only for environmental correction, experiments, or model fitting.

    Air-property constants

    Dry-air density uses the ideal-gas equation. Dynamic viscosity uses Sutherland’s law.

    Aerodynamic coefficients and diagnostics

    The fitted coefficient tables are shown for inspection. The application normally uses them unchanged.

    Nova motor scaling and Spinsight measurements

    The default curve uses measured ball speed and maximum backspin results. The first three low-speed rows are smooth estimates because those measurements were unavailable.

    Spinsight reference curve

    Speed is interpolated from measured km/h. Spin setting is scaled against the maximum measured rps at that speed.

    Rows marked estimated are extrapolated below the first measured speed. All other defaults come from the Spinsight capability test.
